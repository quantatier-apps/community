Use this community to find product information, follow updates, and get help with Quantatier's Darwin and Cloud.

Choose the guide for the task you want to complete. Requirements and supported operations are described in each guide.

## Start with Darwin

1. Follow the installation and setup instructions supplied with your Darwin distribution.
2. Check the product version and the instructions for the feature you want to use.
3. Prepare the strategy, historical data, or supported data connection required by that feature.
4. Run a small example using data you are permitted to use.
5. Review the available results and logs before moving to a larger workflow.

For a first backtest, begin with [CTA Backtester](docs/darwin/local-backtesting.md). Use [Data Manager](docs/darwin/data-manager.md) for questions about supported historical data operations, or [Data Recorder](docs/darwin/data-recorder.md) for live recording requirements.

Product access and supported platforms are described in the instructions accompanying your distribution.

## If you get stuck

Read [Support](SUPPORT.md) for a short question and bug-report template. Include your product, version, operating system, and the steps that led to the problem.

Use English for public questions and contributions. Share only the information needed to explain the issue, with credentials and private data removed.
